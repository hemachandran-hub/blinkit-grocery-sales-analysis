## 📌 Project Overview
This project performs end-to-end data exploration, cleaning, transformation, and business intelligence analysis on Blinkit's grocery sales dataset using MySQL. The goal is to uncover key drivers of sales performance across different product categories, fat content types, and store outlet profiles.

---

## 📁 Repository Structure
- `blinkit_analysis.sql` - Complete SQL queries covering table creation, data cleaning, feature engineering, and KPI analyses.
- `blinkit_dataset.csv` - The raw Blinkit grocery sales dataset used for analysis.
- `README.md` - Documentation, schema overview, and key business insights.

---

## 🛠️ Tech Stack & Database Engine

## 🗂️ Database Schema & Data Model
The analysis operates on the `blinkit` table within the database schema:

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| `Item_Identifier` | `VARCHAR(20)` | Unique product ID |
| `Item_Weight` | `DECIMAL(6,3)` | Product weight |
| `Item_Fat_Content` | `VARCHAR(20)` | Regular vs Low Fat |
| `Item_Visibility` | `DECIMAL(10,6)` | Display area percentage |
| `Item_Type` | `VARCHAR(50)` | Product category |
| `Item_MRP` | `DECIMAL(10,4)` | Maximum Retail Price |
| `Outlet_Identifier` | `VARCHAR(30)` | Unique store ID |
| `Outlet_Establishment_Year` | `INT` | Year store was established |
| `Outlet_Size` | `VARCHAR(20)` | Small, Medium, or High |
| `Outlet_Location_Type` | `VARCHAR(20)` | Tier 1, Tier 2, or Tier 3 |
| `Outlet_Type` | `VARCHAR(50)` | Store type (e.g., Supermarket, Grocery Store) |
| `Item_Outlet_Sales` | `DECIMAL(10,4)` | Total revenue generated by the item |
| `net_quantity` | `DECIMAL(10,2)` | *Derived:* Estimated units sold (`Sales / MRP`) |

---

## 🔍 Key Data Cleaning & Transformations 
1. **Primary Key Setup:** Defined a composite primary key (`Item_Identifier`, `Outlet_Identifier`) to prevent duplicate entries.
2. **Data Standardization:** Uniformed inconsistent categorical entries in `Item_Fat_Content` (`'reg'` $\rightarrow$ `'regular'`, `'LF'` $\rightarrow$ `'low fat'`).
3. **Feature Engineering:** Calculated `net_quantity` (`Item_Outlet_Sales / Item_MRP`) to approximate total volume/units sold per item.

---

## 📈 Key Business Questions Addressed
- **Top Performers:** Identified the top 10 revenue-generating products and categories.
- **Outlet Performance:** Evaluated how average sales vary across Outlet Types (Supermarkets vs Grocery Stores) and Outlet Sizes.
- **Geographic Tiers:** Analyzed sales distribution across location types (Tier 1, Tier 2, Tier 3).
- **Product Analysis:** Evaluated sales by `Item_Fat_Content` and calculated average MRP per category.
